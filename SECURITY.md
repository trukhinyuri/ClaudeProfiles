# Security

Claude Profiles runs locally, has no network code, and never reads sign-in credentials or tokens. If you find a way it could expose account data, lose user files or be used against Anthropic’s terms, please report it privately through [GitHub Security Advisories](https://github.com/trukhinyuri/ClaudeProfiles/security/advisories/new) rather than a public issue. I aim to respond within a week.
